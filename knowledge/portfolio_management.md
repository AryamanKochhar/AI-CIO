# Portfolio review

Educational review context, not a financial instruction.

Review recorded objectives, liquidity, liabilities and goal timing before discussing allocation. Keep willingness, financial capacity and required return separate. Use an observed-fact → significance → conditional-options → trade-offs → next-action structure. Missing context limits a conclusion; it is not a reason to fabricate a second finding.
